VS Code 的真正威力来自丰富的插件生态。本文精选 20 个 2026 年最值得安装的 VS Code 插件。

## 一、AI 编程类

1. **Codeium** - 免费 AI 补全
2. **GitHub Copilot** - 业界标杆（免费版够用）
3. **Tabnine** - 注重隐私的 AI 助手
4. **CodeGeeX** - 国产开源

## 二、代码美化

5. **Prettier** - 代码格式化
6. **ESLint** - JavaScript 代码检查
7. **Stylelint** - CSS/Less 检查
8. **SonarLint** - 多语言代码质量

## 三、效率工具

9. **GitLens** - Git 增强
10. **Project Manager** - 多项目管理
11. **Todo Tree** - 代码注释待办
12. **Bookmarks** - 代码书签
13. **Auto Rename Tag** - 自动重命名标签
14. **Path Intellisense** - 路径补全
15. **Chinese Lorem** - 中文假数据

## 四、主题外观

16. **One Dark Pro** - 经典主题
17. **Material Icon Theme** - 文件图标
18. **JetBrains Mono Font** - 程序员字体

## 五、远程开发

19. **Remote - SSH** - 远程开发
20. **Live Server** - 本地服务器
