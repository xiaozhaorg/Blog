Trae 是字节跳动 2025 年推出的 AI 原生 IDE，本文深度体验。

## 一、Trae 核心模式

### 1. Chat 模式
类似 Copilot Chat，可以问代码问题

### 2. Builder 模式
**杀手锏功能**：从需求到代码全自动

### 3. Inline Edit
选中代码后 `Cmd I` 自然语言编辑

## 二、Builder 模式实测

### 任务：开发一个 TODO 应用

输入：
"开发一个 TODO Web 应用，支持增删改查、本地存储、暗黑模式"

Trae 自动：
1. 创建项目结构
2. 写 HTML/CSS/JS
3. 实现功能
4. 测试运行
5. 给出预览链接

整个过程 3 分钟，无需手动写代码。

## 三、对比 Cursor

| 维度 | Trae | Cursor |
|------|------|--------|
| 中文支持 | 极强 | 一般 |
| 完全免费 | ✅ | 部分 |
| Builder 模式 | ✅ | Composer |
| 生态插件 | 基础 | VS Code 全兼容 |
| 性能 | 优秀 | 优秀 |

## 四、优势

- 完全免费（目前）
- 中文理解最佳
- Builder 模式惊艳
- 国内访问快
- AI 模型可选

## 五、不足

- 插件生态还在完善
- 大项目支持待优化
- 偶尔有 bug
- 国际化支持待加强

## 六、推荐场景

- 中文母语开发者
- 快速原型开发
- 学习编程
- 小型项目
- 不想花钱的用户
