GitHub Student Developer Pack 是学生党的福利，几十个付费服务全部免费，总价值超过 $1000。

## 一、申请条件

- 在校学生
- 有学校邮箱（.edu 或学号邮箱）
- 上传学生证或在读证明

## 二、申请流程

1. 访问 https://education.github.com/pack
2. 点击 "Get the Pack"
3. 登录 GitHub
4. 验证学生身份
5. 上传证明材料
6. 等待审核（通常 1-3 天）

## 三、必薅羊毛清单

### 云服务
- **DigitalOcean** - $200 额度（约 14 个月 VPS）
- **Microsoft Azure** - $100 额度
- **AWS Educate** - $100 + 额外资源
- **Heroku** - $13/月 × 2年

### 域名 & 网站
- **Namecheap** - 免费 1 年 .me 域名
- **.tech 域名** - 免费 1 年
- **GitHub Pages** - 免费静态托管
- **Netlify** - 免费托管

### 开发工具
- **JetBrains 全家桶** - 免费（IntelliJ IDEA、PyCharm 等）
- **GitHub Pro** - 私有仓库无限
- **GitHub Copilot** - AI 编程免费
- **DataCamp** - 数据科学课程
- **Educative** - 编程课程

### 设计 & 资源
- **Figma** - 专业版免费
- **Canva** - 高级版免费
- **Icons8** - 图标素材

## 四、注意事项

1. 毕业后会失去部分权益
2. 同一服务只享受一次
3. 部分需要信用卡验证
4. 建议用学校邮箱注册

## 五、推荐组合

- JetBrains + GitHub Copilot（编程）
- DigitalOcean + Namecheap（建站）
- Figma + Canva（设计）
- 全部组合可省下大笔费用
