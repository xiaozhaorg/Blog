Cursor 是基于 VS Code 开发的 AI 原生 IDE，号称"AI 编程的未来"。本文深度体验并对比 VS Code + Copilot。

## 一、Cursor 核心特性

### 1. Cmd K 命令面板
随时按 `Cmd K` 调出 AI 输入框，自然语言编辑代码。

### 2. Composer 模式
跨文件编辑，AI 能理解整个项目结构。

### 3. Tab 自动补全
比 Copilot 更激进的 AI 补全策略。

### 4. @ 引用
`@file` `@folder` `@web` `@docs` 引用上下文。

## 二、实战对比

### 任务：用 Python 写一个爬虫

| 维度 | Cursor | VS Code + Copilot |
|------|--------|------------------|
| 首次生成准确率 | 95% | 80% |
| 跨文件感知 | ✅ | ❌ |
| 调试能力 | 强 | 中 |
| 学习成本 | 低 | 低 |

## 三、定价

- **免费版**：2000 次 AI 补全/月
- **Pro**：$20/月
- **Business**：$40/月

## 四、优缺点

### 优点
- AI 深度集成，体验丝滑
- Composer 模式强大
- 基于 VS Code，迁移成本低
- 支持自定义模型

### 缺点
- 偶尔卡顿
- 隐私顾虑（代码上传云端）
- 部分插件不兼容
- 收费较高

## 五、是否值得迁移？

- **AI 重度用户** → 强烈推荐
- **VS Code 老用户** → 可先试免费版
- **企业项目** → 评估隐私后决定
- **学生/个人** → 强烈推荐
